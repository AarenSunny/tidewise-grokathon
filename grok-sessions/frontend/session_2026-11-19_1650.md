## Plan / tradeoffs
- Never show a gate that can't be confirmed as safe: `cannot_confirm` renders as "Can't confirm" / "Check advisory".
- Keep example data visibly labeled; fall back to it only when live calls fail or return no windows.
- Use 72h `/recommend` ranges; 24h often returned zero windows (no daylight minus tide).
- Crabbing sends `gear=hoop_net`.
- Day picker filters the 72h live result client-side (no new backend calls) to ship safely in minutes.
